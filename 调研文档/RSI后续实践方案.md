## 0. 一句话诊断

**v6–v13 的 SFT 线是一条优秀的"开环调参曲线"，但不是 RSI**——每个实验都从基座重训一次、和基线比一次，改进产物没有回流为下一轮的输入。按纲领§2.1 的判据（回路闭合性：改进产物 O_t 受控回流为 I_{t+1}，"改进率的改进率"非零），目前只有 v1–v4 是闭环（但权重坍缩），v9/v10 让权重通道首次转正（但开环）。**两个条件第一次同时具备，下一步就是把回路重新闭合，并补上 RSI 独有的证据（C4 swap test）。**

**链条的元教训**：13 步里真正改变符号的只有 v9 一步（消除训练/评估分布错配），其余是排除（v6–v8、v11–v12）和机制建设（v3）。这正是 RSI-Forge 的发现——超基线的 session 中 **95% 做的是结构层工作而非调参**。RSI 的进步来自消除结构性障碍，不来自堆量。

另一个元观察：**v1→v13 本身就是一次成功的 RSI**——改进对象是训练管线，改进者是"实验者 + AI 助手"，每步都被 held-out + McNemar 验证门把关，13 代迭代把权重通道从 −15pp 做到 +3.85pp。问题在于这个回路只存在于 markdown 里，系统自己读不到（见 §4）。

## 3. 用评测宪法逐条落实"RSI 的特点"（HANDOFF §10 的 C1–C5）

RSI 的特点不是"分数涨了"，而是五个主张层级逐级变难。文献实测：90 篇自称 RSI 的研究里 60% 只验证 C1；**"R"（递归）的证据几乎无人提供**。逐条落地：

| 主张 | 含义 | 现状证据 | 后续实践 |
|---|---|---|---|
| **C1** 产品增益 | 最终 > 初始 | arm_H 66%（+9pp）、D 61.85%（+3.85pp） | D×H₅ 四变体补齐 |
| **C2** 跨轮累积 | 增益跨代保持 | v1–v4 有 5 代曲线（harness 线）；SFT 线无 | 3–5 代共进化，**记录每代增益率**，要求不为负 |
| **C3** 可复现 | 独立重跑增益再现 | D 的 seed2 复现了单点 | **第二 seed 全环重跑**（满足 audit 论文"≥2 次全环"门槛，仅 22% 研究做到） |
| **C4** 改进者增益 | **更晚的改进者从同一起点、同预算产出更好的后代** | **零证据（文献中也仅 4/26 篇做同起点对照）** | **swap test**：gen-0 改进器 `(W₀,H₀)` vs gen-N 改进器 `(W_N,H_N)`，作用于同一 fresh 基座、同预算、各训一代、审计其后代 |
| C5 复利 | 改进者增益自身增长 | 不主张（5 代视野太短） | 诚实声明不主张——这本身就是与"市面伪 RSI"的区别 |

**C4 是"R"字本身**，也是本项目最大差异化（HANDOFF §7.5 定位：对 78% 不审计过程的研究的示范）。做完 swap test，项目就从"复现 Self-HPI Table 1 的最小 SFT 版"升级为"提供几乎无人提供的 C4 证据"。

**由命题 1（空环基准）导出的两个防伪机制必须配齐**（v2 晋升门事故、v12 promo 69% 假象已两次实证其必要性）：
- **空对照臂**：判分反馈随机打乱、选择照常跑 → held-out 应平坦，其 dev 曲线涨幅 = 虚假增益的直接估计；
- **噪声感知晋升规则**：margin δ + promo-val ≥100 + McNemar（v13 已列入统计要求）。

## 4. 知识回流：把"人肉 RSI"升级为"系统 RSI"

这是 ForgeKernel（[精读笔记](精读笔记/ForgeKernel_2611.04998.md)）和 RSI-Forge（[精读笔记](精读笔记/RSI-Forge_2610.09426.md)）给本项目最直接的机制启示：

1. **教训库**：把 v1–v13 已验证的教训结构化为机器可读的经验库，条目 = 机制 + 适用条件 + 触发症状 + 证据（如"外部数据混合 → 混合集显著退化，p=0.0308，适用：中文数学域/3B"）。Phase A 的提议者 agent 检索并显式引用——**先追平自己，再超越**。
   - 入库门槛照抄 ForgeKernel：**必须带独立验证证据**（held-out + 配对检验），无证据的直觉不入库；
   - RSI-Forge 侧证：继承"代码 + 笔记"让 84% 环境持续改进——我们的"笔记"就是这个教训库。
2. **失败条件化 probe**（已实现，保持）：harness 搜索永远瞄准当前权重的失败模式（Self-HPO +1.5pp 实证）。
3. **封存机制**：每代通过晋升门的最优 `(W,H)` 组合封存为下一代基准（v3 的归档回滚 + best_adapter 已是雏形），跨代只增不减。
4. **新熵防自噬**：env_gen 外生任务流；**v8 的教训要写进数据纪律**——同分布自生成成功样本放大 10 倍反而更差，跨代累积回放必须配合任务分布演进，不能只回放已解题型。

### 结语：何谓"体现出 RSI 的特点"

一句话：**让改进的产物和改进的经验都以受控方式回流，并且用 swap test 证明"改进者自己变好了"**。做到这三件事——回路闭合（v13 步骤 1–2）、知识回流（§4）、C4 证据（§3）——本项目就同时区别于"堆算力的伪 RSI"（60% 只验 C1）和"无审计的自进化宣传"（78% 不看过程），在单机规模上给出领域内几乎无人提供的递归证据。
