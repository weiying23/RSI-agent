# RSI 文献综述：双通道自我提升（Self-HPO 与 CoEvo-RSI）

> 整理自 test-RSI 项目的文献调研与两轮实测。核心两篇：Self-HPO（2610.22791）与 CoEvo-RSI（2610.25078），支撑文献 STaR、Anthropic AAR、Auditing RSI、RSI Arena 等。

---

## 一、背景

### 1.1 RSI 的定义与唯一判据

RSI（Recursive Self-Improvement，递归自我提升）的判据不是"会改自己"，而是**回路闭合性**：改进系统的产物 O_t 必须以受控方式回流，重新构成下一代改进系统 I_{t+1}。判据是"改进率的改进率"非零——**改进者本身被改进**。

据此可把现有系统分成一个 L0–L4 谱系：

| 层级 | 改动对象 | 代表 |
|---|---|---|
| L0 | 脚手架（prompt/skill/记忆/工具/工作流） | Voyager、Agent Zero、HarnessPro |
| L1 | 数据层（agent 选数据，人按训练键） | 各家实验室数据飞轮 |
| L2 | 权重闭环（自生成+验证→微调→新权重做下一代生成器） | STaR、Self-Rewarding LM、Absolute Zero |
| L3 | 元层（agent 改改进过程本身） | Darwin Gödel Machine、Gödel Agent |
| L4 | 架构/目标层 | AlphaEvolve（仅对外） |

**市面绝大多数"RSI"产品停留在 L0**：改进的是模型周围的脚手架，改进者（冻结的模型）从未被改进。Auditing RSI（2610.27610）对 114 篇研究的实测给出背书：90 篇自称 RSI，仅 22% 审计了递归过程本身，60% 用未参与选择的数据评估。

### 1.2 双通道：从空白到被填补

真正"彻头彻尾"的自进化 = L2（权重）+ L3（harness/过程）二者兼有。BAAI kernel 综述（2601.15727）在 2026-06 曾把 "long-horizon agentic training + autonomous harness engineering" 并列为未来方向——即"双通道无人同时做"。

**这一空白在 2026 年下半年被密集填补**，标志性工作即本文综述的两篇：

- **Self-HPO**（2610.22791）：harness 与 policy 交替优化，策略自己当 harness 提议者。
- **CoEvo-RSI**（2610.25078）：引入共享进化档案与"脑体错配"概念，解决协同进化中的失配。

## 二、问题

### 2.1 单边孤立的致命缺陷

以往工作要么只改权重（Policy-only，RL 微调、脚手架写死），要么只改脚手架（Harness-only，权重冻结）。孤立的两派各有天花板：Policy-only 的 harness 不匹配模型能力、白白浪费；Harness-only 受冻结模型能力上限封死。**更好的 harness 能暴露并纠正权重的弱点，更强的权重也能反向激发 harness 的潜力——二者必须绑定循环。**

### 2.2 脑体错配（Brain-Body Mismatch）

CoEvo-RSI 指出的更深层矛盾：在持续交替进化中，harness（体）与模型权重（脑）会失配，分两类：

- **接口错配**：进化的 harness 改了输出/调用要求（如突然要 JSON），模型习惯的格式被拒，正确逻辑被判错。
- **能力错配**：harness 引入模型没学过的能力，或意外阉割了模型原有能力。

用廉价指标 **TIMR（回合级接口失配率）** 可测接口错配。

### 2.3 评估是第一瓶颈

Anthropic AAR 的结论"生成便宜、评估昂贵"在 RSI 领域同样成立：没有防篡改的评估层，递归会放大自我欺骗与 reward hacking。Auditing RSI 进一步指出**选择与结论必须分离**——否则"用谁评我，我就讨好谁"。

## 三、主要工作

### 3.1 Self-HPO：交替双向协同优化

把 agent 形式化为 (H, P)：H = harness（提示词、工具、反馈、终止逻辑），P = policy（模型权重）。目标是在可执行验证器的二值打分下最大化解决率。循环两阶段：

**H-step（改手册，冻结 P）**：当前 (H, P) 在搜索集上跑出失败轨迹 → P 自己分析失败、提出对 harness 的修订（**P 既是解题者又是 harness 提议者**）→ 迭代出 K 个候选 → 保留最优 H。

**P-step（训权重，冻结 H）**：新 H 下做 RL（GRPO + BAR，BAR 用自适应补采样对抗稀疏奖励）更新 P → 从 rollout 提取"全失败的难题集"作下一轮搜索集。

**两个反馈回路**：搜索集演化使 harness 始终瞄准权重的失败模式；更新后的 P 成为下一轮更好的 harness 提议者。

### 3.2 CoEvo-RSI：归档 + 双向历史继承

针对脑体错配，核心是**不能让模型单向跟随环境，而要双向继承历史**：

1. **诊断**：现役 (H, 模型) 在验证集跑、找失败；
2. **馆长（Curator）**：检索共享档案（历史 harness、模型检查点、执行记录），提出 K 个修改假设；
3. **K 个编辑器**：各从档案选一个历史 harness 当底子改，保留谱系；
4. **模型继承**：为每个新 harness 配模型——单选检查点，或 **TIES 合并**多个检查点；
5. **选拔**：验证集选最优对；
6. **适应**：拒绝采样（只留验证器接受的）→ SFT 对齐脑体；
7. **晋升门**：新组合增益超过 margin 才晋级，否则原地——回归保护默认开；
8. **归档**：全部结果（含失败）入档供后续继承。

### 3.3 支撑工作

- **STaR**（2203.14465）：只微调导致正确答案的推理，rationalization 破冷启动——verified-only 蒸馏的源头。
- **Anthropic AAR**：评估第一瓶颈、reward hacking 必现、泛化是改进与过拟合的分界。
- **Auditing RSI**（2610.27610）：五层主张 C1–C5，指出"固定改进者的循环可以让 C1–C3 全为真"——迭代改进 ≠ RSI。

## 四、效果

### 4.1 Self-HPO（Qwen3.5-35B-A3B，SWE 任务，2 轮交替）

| 做法 | SWE-Bench Verified |
|---|---|
| Base | 61.0 |
| 纯策略（Policy-only） | 67.5 |
| 纯 harness（Harness-only） | 65.2 |
| **双通道（Self-HPO）** | **69.5** |

关键消融：

- **RFT（拒绝采样微调自身成功轨迹）70.5 vs RL 71.6，差 1.1pp** → SFT 路线成立，无需昂贵 RL；
- 固定搜索集 −1.5pp → 失败条件化有效；
- 自提议 −2.1pp（vs Opus 外部提议）→ 闭环纯度只花 2 个点。

域外泛化：仅用 Python 训练，SWE-Bench Multilingual 仍从 54.2% → 59.7%。

### 4.2 CoEvo-RSI（Qwen3.5-9B，多垂直领域）

- 用自身拒绝采样数据 SFT，中小模型比肩/超越更大模型；
- 单侧进化（harness-only）落后 **11.49pp**；
- 十轮累积 **+11.11pp**，同时 TIMR ≤ **0.22%**（脑体未脱节）。

## 五、启示

### 5.1 对领域的通用启示

1. **环境工程与模型能力同等重要**——大模型被困在笨拙脚手架里发挥不出。
2. **知识优先放 harness 而非一味 SFT**——SFT 蒸馏权重易过拟合特定领域；写进 harness 的控制逻辑更通用、更稳健迁移。
3. **递归自提升不能盲目迭代**——harness 进化越快，脑体裂痕越大；不做版本回溯与对齐，模型会被自己的"身体"拖垮。
4. **历史继承是防退化的锚点**——档案 + 检查点选择/合并 + 晋升门，是防止自我提升走向退化的关键。
