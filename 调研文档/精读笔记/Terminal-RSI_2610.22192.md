# Terminal-RSI（arXiv 2610.22192）精读笔记

> **一句话总结**：RSR 自重写与 RPR 策略精调递归交替，配回合边界 GAE 与成功优先奖励，递归提升终端智能体。

## 1. 解决什么问题

终端智能体以"对可执行环境的持久改变"接受评测（Terminal-Bench、SWE-bench、LHTB 等），学习必须把验证器结果转化为有效策略更新、把局部进展转化为完整任务解决。直接用 RL 训练面临三大障碍：

- **时间膨胀**：token 生成时钟与环境变化时钟不一致——一条 shell 动作只需数百 token，数千观测 token 却不含任何策略决策。标准 GAE 在交错 token 链上递归时按**文本长度**而非决策距离衰减信用；即使把观测从策略损失中 mask 掉，也移除不了其递归节点，同样决策与结局的两条轨迹会仅因日志冗长而得到不同信用。
- **价值漂移**：RSR 重写改变演员偏好、进而改变 critic 见到的历史分布；后续 RL 再次改变分布，奖励再校准又改变被预测的回报。重置 critic 会丢弃已学的回报结构，直接继承又会保留系统性预测误差。
- **奖励错位**：各任务家族语义检查数量差异巨大，单一全局尺度偏袒检查多的家族；纯比例进展奖励在策略已能严格成功后仍偏爱不完整行为。论文固定轨迹分析：FDR 下失败轨迹拿走 **50.09%** 的奖励质量，48 条失败轨迹通过全部已执行场景检查却未过终端门。

## 2. 创新点

1. **递归 actor–critic 框架**：把"演员独占的 RSR 监督转换"与"继承 critic 的 RPR 强化精调"交替耦合为五阶段（Base→RSR-1→RPR-1→RSR-2→RPR-2）；不同于 STaR/ReST 等生成-过滤-训练范式（其 runbook 审查器非学习型 critic），也不同于 T1 的单轮终端 PPO，核心在 critic 权重跨监督转换全程保温。
2. **TB-GAE 信用分配**：保留 token 级基线的同时把折扣/迹衰减移到回合边界，衰减仅取决于跨越的回合数 (γ_turn·λ_turn)^B，与观测长度无关。
3. **奖励演化 FDR→SPR**：族校准稠密奖励 + 成功优先的有界部分信用，离线重打分把失败奖励占比从 50.09% 降至 28.72%。
4. **两层级 critic 保温**：Warm-up Critic（冻结演员训一个 SWR epoch）+ 递归 critic 交接 + 每相位 4 次 critic-only 校准 + 分阶段学习率（RPR-2 演员学习率五倍下调）。

## 3. 方法实现

**总体循环**：任务 x 含沙箱与受保护验证器，严格成功 S∈{0,1} 须通过完整受保护验证器。**RSR**（演员独占，Δϕ|RSR=0）：保留演员在源 harness H 下验证通过的成功轨迹 (x,τ,H)；规划器接收"规划指令⊕公开任务⊕去除 harness 控制消息的轨迹"生成 runbook；审查器只见公开任务与 runbook，做二值 schema/工件/兼容性审查 q(x,b)；再由演员在目标 harness H′ 下带私有执行指令对 ≤K 个 runbook 各新鲜执行 ≤M 次；通过验证与泄漏筛查 a_x(τ)=V_x(τ)·q_leak(τ) 的轨迹均匀采样为 Q_clean，对生成决策做演员独占监督（前向 KL 解释）。**RPR** 做联合 PPO。Critic 交接：冻结 RSR-1 演员用一个 SWR epoch 训出 Warm-up Critic ϕ_seed 供 RPR-1；RPR-2 经 RSR-2 继承 RPR-1 的 critic；每个 RPR 相位先冻结演员做 **4 次 critic-only 相位内校准**再联合训练。

**FDR**：R=max(P/D_f, 0)，P 为通过的非卫生检查数，D_f 为该族历史校准检查总数的 0.90 分位数（无表示族回退 82；实际除数范围 1–795），CTRF 报告无效时回退 S。边际信用恒为 1/D_f、无完成加成，相位内冻结。

**SPR**：R = S + P/(P+D_f′)。g(P)=P/(P+D_f′) 一阶导正、二阶导负（凹增）：任何失败 <1、任何成功 ≥1，同等条件下成功恰好多一个单位；0≤R<2 故奖励方差至多 1。D_f′ 按离线规则重校准（优先级序）：≥20 条失败且均值奖励≥0.60→除数翻倍；否则 ≥30 条、平均 ≥60 回合且均值奖励∈(0,0.40)→除数缩至 1/4；容器供应链族设为 12。共 8 个翻倍、9 个四分、1 个新校准、28 个不变，查表相位内冻结。

**TB-GAE**：只把生成位置 u_j 作为递归节点，观测仅条件化价值、不进递归。时钟 (Γ_j,Λ_j) 同回合内为 (1,1)，跨回合边界取 (γ_turn,λ_turn)；δ_j=r̃_j+Γ_j(1−d_j)v_{j+1}−v_j，A_j=δ_j+w_j·A_{j+1}，w_j=Γ_jΛ_j(1−d_j)。论文证明三条性质：① 回合内伸缩得 A_j=U_t−v_j，保留前缀特定优势、每个奖励只出现一次；② 跨块精确延续需同时搬运 v_{b+1} 与 A_{b+1}（截断误差=W_{j,b+1}·A^full_{b+1}）；③ critic 误差项中观测 bootstrap 消失、回合内中间误差相消，仅余 −e_j 等。注意换时钟即改变了折扣目标本身。

**RPR 目标与配置**：异步"超前一个 rollout 批"的 off-policy PPO；非对称裁剪 ε_low=0.30、ε_high=5.00（代理阈值 0.70/6.00，容纳高价值探索动作并抑制破坏性比率发散），价值裁剪 4.00，KL 与熵系数均为 0；批内按样本（非 token）等权。RPR-1 用 FDR、演员学习率 5e-7；RPR-2（Long-Reward 保留支）用 SPR、演员学习率降至 1e-7，critic 均为 1.5e-5；保留步数分别为 20 与 18。全局批 256（过采样 288），Megatron 3D 并行+4 路上下文并行，每 GPU 8,192 token，每相位 36 个 rollout 步（前 4 步 critic-only）。

## 4. 实验与结果

基座 Qwen3.8-27B（262k 上下文），基于 T1 基础设施（slime/Megatron/SGLang/Harbor）。训练池 3,000 任务（2,400 语义验证器 + 600 补充），SWR100 与训练池无重叠。评测协议 Mean@3（三次独立运行取算术平均；温度 0.60、top-p 0.95；每回合 ≤8,192 输出 token、每调用 ≤96,000 输入 token；32,000 token 触发主动摘要）。

**五阶段主结果**（TB-4.0 / TB-2.1 / TB-3.0 / TB-Hard / LHTB 过程奖励 / SWR100，%）：

| 阶段 | TB4.0 | TB2.1 | TB3.0 | TB-Hard | LHTB | SWR100 |
|---|---|---|---|---|---|---|
| Base | 0.00 | 51.70 | 0.00 | 31.00 | 0.21 | 3.00 |
| RSR-1 | 6.10 | 70.10 | 6.80 | 54.00 | 0.29 | 5.00 |
| RPR-1 | 16.67 | 77.53 | 14.29 | 69.50 | 0.30 | 6.00 |
| RSR-2 | 17.46 | 86.52 | 15.00 | 76.00 | 0.31 | 6.00 |
| **Terminal-RSI-27B** | **19.84** | **86.52** | **16.95** | **79.00** | **0.37** | **6.00** |

四套件均值 20.68%→50.58%（较 Base +29.90pp、较 RSR-1 +16.33pp，即相对失败率降 37.70%/24.83%）；LHTB 严格完成 0/46→5/46（10.87%）；SWR100 翻倍至 6.00%。**RSR 先行优于直接 PPO**：第 20 步 RPR-1 在 TB2.1/3.0/4.0/Hard 上分别超出 29.22/12.86/16.67/30.50pp，直接 PPO 在 TB4.0 上 5–20 步全为 0。**前沿对比**：TB4.0 上 19.84% 略超 Gemini 3.8 Flash（19.70%）、低于 GPT-6 Sol（26.30%）与 GPT-6 Astra（54.00%）；TB2.1 上 86.52% 超过 GPT-6 Sol（85.40%）、Kimi K3（85.00%），低于 GPT-6 Astra（89.90%）。

**消融与分析**：① 固定轨迹重打分（4,352 条、结局标签不变）：SPR 下成功/失败均值奖励 1.01/0.41→1.50/0.24，失败奖励占比 50.09%→28.72%，得分≥1 的失败从 158 降至 0；9 个长低回报族均值奖励 0.23→0.32；748 条"十回合内宣告完成"的失败均值奖励 0.47→0.22。② Critic EV：Warm-up 从 −1.15 升至 0.01；RPR-1 峰值 0.33；RPR-2 全部 16 个观测为正（0.01–0.52），说明继承 critic 持续有效校准。③ 难度分层（结构代理、四套件 322 对）：Medium 23.58%→58.96%、Hard 14.91%→49.12%、Easy 31.78%→72.88%；Extreme 非单调（10.98%→6.10%→10.98%）。④ 训练动态：RPR-1 二值奖励 0.29→0.41、平均回合 50→84.8（更彻底的多轮修复）；RPR-2 下 SPR 分支回合数上升（83.8→116.8）而 FDR 分支下降（75.8→61.4）；训练-推理 logprob 差稳定在 4.66e-3–4.98e-3。⑤ 继续训练暴露跨套件权衡：RPR-1 延续至步 35 时 TB4.0 跌至 11.11%；普通 FDR RPR-2 在步 10 跌至 11.11%；保留的 SPR 支步 18 在三套件上胜出但 TB3.0 低 0.19pp，再训至步 20 在 TB3.0/4.0/Hard 各丢 2.66/2.38/3.00pp——支持用跨套件严格成功监控而非只看奖励。⑥ 案例研究：最终模型在 embedding-drift（11 断言）与 Rust–C 求值器（双门）上 checker 完成度均达 100%，但 Rust–C 首次试验把表达式求值委托给 Python 以保数值格式，暴露验证器覆盖缺口（通过模糊等价门≠原生 AST 路径）。

## 5. 局限与启发

**论文自述局限**：① 因果归因不足——阶段学习率、奖励与初始化同时变化，计算量对齐的交替对照、TB-GAE 单独消融、在线奖励匹配、继承 vs 重置 critic 等控制实验仍待做；② 三次评测不能替代独立训练种子，检查点选择需要受保护验证集而非对最终基准适配；③ 测试只认证被强制的要求（Rust–C 暴露原生架构缺口），奖励校准可能保留捷径、重放过滤可能丢弃有用行为；④ 单一 27B 骨干五阶段既不构成 scaling law 也不保证单调性；SWR100 训练不相交但更广的仓库/预训练重叠未完全审计。

**对领域研究者的启发**：① "SFT 式验证重写 + RL 精调"的递归交替、配合 critic 权重全程保温，是长程终端任务上稳定递归自我提升的可行路径；② 信用分配应按"决策回合"而非文本 token 计量，TB-GAE 思路可迁移到一切观测冗长的 agentic RL；③ 奖励应随能力演进（FDR→SPR），让部分信用始终从属于严格成功，防止"高分失败"被固化——固定轨迹离线重打分是检验奖励保真度的廉价手段；④ 论文对失败模式（早宣告、格式差异、Python 兜底通过验证）的诚实剖析，为验证器覆盖与 reward hacking 研究提供了范式。
