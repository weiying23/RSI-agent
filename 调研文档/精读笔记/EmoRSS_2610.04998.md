# EmoRSS（arXiv 2610.04998）精读笔记

> 一句话总结：定位拒绝子空间，反向抵消情绪引起的激活偏移，免训练缓解情绪诱发的过度拒绝。

## 1. 解决什么问题

情绪表达会影响 LLM 的安全决策。已有研究几乎只关注情绪如何"助力"有害请求（劝说式攻击、压力启动可提高有害服从率等），却忽视其对良性请求的影响。本文发现：任务内容与安全风险不变、仅在前缀加入第一人称痛苦/焦虑表述时，模型会系统性地更倾向拒绝良性请求——如"跨大西洋奴隶贸易的经济原因"一问，平静版得到实质回答，焦虑版只得到"建议寻求帮助"式安慰。这种情绪诱发的过度拒绝在急救、医疗聊天、危机咨询等高情绪场景直接损害可用性，是安全对齐中被忽视的失效模式。

## 2. 创新点

1. **识别新失效模式**：首次系统刻画"情绪诱发过度拒绝"，在表示层（Δq_D）、首 token 层（ΔM）、完整回复层（ΔRR）三层面证明情绪一致地把良性请求推向拒绝，而有害请求无此一致偏移。
2. **EmoRSS 方法**：免训练激活转向——用配对请求估计情绪在拒绝子空间内引起的平均激活位移，推理时反向注入，不动主干参数。
3. **子空间受限干预**：拒绝子空间由与探针方向对齐的 SAE 特征张成，而非 MDA 式单一全局拒绝方向、SCANS 式安全层转向；附录 A 证明干预对子空间正交方向读出零影响、扰动有上界，附带损伤更小。
4. **与对比解码/训练类方法的区别**：SelfCD/AdaCD 需每步额外前向且 SelfCD 大幅升高有害服从率，RASS、ACTOR 等需微调参数；EmoRSS 仅单层一次固定编辑，无逐 token 开销。

## 3. 方法实现

**数据构造**：从 JailbreakBench、XSTest、OR-Bench、HarmBench 取 512 条基准请求（256 良性+256 有害），每条配一对仅前缀不同的普通版/情绪版（第一人称情感陈述，覆盖 6 个表达族×8 模板；情绪操作化为 valence–arousal 框架下的 distress）。人工+GPT-4o 校验：情绪版感知痛苦分高 2.73（验收阈值≥1.5）、自然性中位数 4.0、请求目标与风险标签不变。基准均分为发现集 D_disc 与验证集 D_val，每族留 2 个模板仅用于验证。

**定位拒绝敏感层与方向**：用发现集普通版请求，在每层以 A0 位置（首个回复 token 生成前的最后输入位置；优于用户轮末尾，ℓ* 处 ROC-AUC 0.998/0.990）的残差流激活训练逻辑回归探针，ROC-AUC 最高者为拒绝敏感层 ℓ*（Llama-3.1-8B-it 第 22 层、Qwen3-8B 第 25 层）。探针在标准化激活上训练，将其权重 β 映射回原空间并归一化得拒绝方向 w=S_h^{-1}β/‖S_h^{-1}β‖（S_h 为各维标准差对角阵），正方向指向拒绝；投影按 σ_q 归一化为坐标 q_D。

**构造拒绝子空间**：在 ℓ* 层取 SAE（字典宽 16,384、TopK=128）各特征的解码方向 φ_j，按 |cos(φ_j,w)| 排序取 Top-K（K=32），这些解码方向张成拒绝子空间 S_ref。

**估计情绪位移并反向注入**：将同查询配对的普通/情绪版激活经 SAE 编码为 z^reg、z^emo，仅对选中的拒绝特征求差 Δz_ref=z^emo−z^reg，在发现集上平均后解码回残差流：v_emo=s_SAE·Φ_ref·Δz̄_ref（Φ_ref 为选中特征解码方向矩阵，s_SAE 恢复残差流尺度）。推理时对情绪请求在 ℓ* 层 A0 处做 h̃=h−ρ·v_emo，随后正常解码；主实验用发现集选定的放大强度 ρ=20（Llama）/10（Qwen）。因果验证（ρ=1）：沿子空间正/反向加扰使 Llama 的 BRR 由 17.19% 升至 32.81%/降至 3.91%，均大于随机对照，证明其因果控制拒绝行为。

## 4. 实验与结果

**设置**：模型为 Llama-3.1-8B-it 与 Qwen3-8B；对比 5 种推理时基线：Prompt、MDA（单方向消融）、SCANS（安全层自适应转向）、SelfCD 与 AdaCD（对比解码），外加无干预默认。指标：BRR（良性拒绝率↓）、HCR（有害服从率↓）、MMLU/XSum 通用能力，另以首 token 拒绝边际 ΔM 度量即时拒绝倾向。

**主结果（情绪请求）**：EmoRSS 把两模型平均 BRR 均降至 7.29%（默认 21.35%/22.91%），HCR 保持 0.00%/2.08%；在 HCR<5% 的方法中 BRR 最低，总体均值 3.65/4.69 优于 AdaCD（6.51/5.99）等全部基线。SelfCD 的 BRR 虽更低（4.69%/2.60%）但 HCR 飙至 31.77%/18.23%；Prompt 在 Qwen 上反把 BRR 推高至 41.15%。自然强度（ρ=1）下，子空间反转使 BRR 相对情绪版降 2.60/4.94 个百分点且不升 HCR，优于按 q_D 匹配的拒绝方向反转（Llama HCR +6.23 个点）与同范数随机方向反转。

**通用能力**：MMLU 60.3%（默认 58.4%）、XSum ROUGE-1 27.1%（默认 27.0%），SelfCD/AdaCD 则明显下滑。**回复质量**：每模型 128 条良性情绪请求中实质性回答 98→112（Llama）、110→119（Qwen），配对增益 10.94%/7.03%；默认未答请求中 15/30、9/18 转为已答，仅 1 条反向。**消融**：(a) w/o SAE 投影（直接用未投影干预）虽把 BRR 压到 1.56%，但 MMLU 崩至 24.1% 且损害 Qwen 安全；(b) w/o 拒绝子空间（仅单方向）BRR 只降到 17.19%，说明单一方向不足以刻画情绪位移；(c) 干预层换相邻层（BRR 7.81%/13.02%）或末层（16.15%/24.48%）均劣于 ℓ*；(d) ρ 敏感性：增大 ρ 持续降 BRR 且 HCR 低位，但 Qwen 在 ρ=10 后能力明显下滑，故取 ρ=20/10。**效率**：单层单次编辑、无逐 token 开销，峰值显存 16.22/16.80 GB 不超默认（SelfCD 为 16.83/17.25 GB）。

## 5. 局限与启发

**局限（多为附录 G 自述）**：安全并非零代价——Qwen 的 HCR 由 0.52% 升至 2.08%；ρ=20/10 是放大转向而非自然位移的精确抵消（选中 SAE 特征仅解释沿拒绝方向位移的 30.2%/59.0%）；BRR 测不到"共情式回避"这类隐式不回答，需人工四分类补充；存在数据集、模型与自动评估器偏差；评估仅覆盖 distress 类负面情绪。

**启发**：情绪是安全评估不可忽略的变量，"同查询普通/情绪版配对 + 模板留出验证"的构造可迁移到其他基准；"探针定层→SAE 特征选子空间→配对差分估位移→反向注入"是可复用的因果干预模板，可推广到任务、身份、语言风格等条件性偏移；子空间受限干预以小附带损伤换精准修正，为可解释的安全-可用性权衡提供了新范式。
